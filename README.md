# Avenzaire · опросник выбора первого направления

Статический сайт для GitHub Pages: 10 вопросов, четыре осторожных ориентира (код, дизайн, обе пробы, знакомство), краткий итог и бесплатная консультация. Нет сервера, регистрации, форм с контактами, cookies, localStorage, сторонних шрифтов и аналитики. Ответы только в памяти вкладки, пропадают после обновления. GitHub Pages и Telegram обрабатывают обычные технические данные по своим правилам.

## Публикация на GitHub Pages
1. Создать отдельный публичный репозиторий для **сайта** (подходит для бесплатного GitHub Pages). Не публиковать в него исходники бота, платные PDF, рабочую базу, .env или токен.
2. Загрузить **содержимое этого архива** в корень: index.html, style.css, app.mjs, quiz-data.mjs, site-config.js, assets/, .nojekyll. Не оставлять сайт вложенным в папку website/, если хотите главную страницу репозитория.
3. В Settings → Pages выбрать Deploy from a branch → main → /(root). Сохранить и дождаться URL, который покажет GitHub. Названия пунктов интерфейса могут изменяться.
4. Открыть выданный HTTPS-адрес, проверить опрос и Telegram-контакт. Относительные пути работают и на https://USER.github.io/REPO/, и на отдельном домене.
5. В личном чате администратора бота отправить `/setdirectionurl ВАШ_HTTPS_АДРЕС`. Проверить `/directionstatus` и кнопку «Не знаю, что выбрать».

Сайт не требует сборки, npm, GitHub Actions, ключей и платных сервисов. Не вставлять токен Telegram в JavaScript. Для обновления достаточно заменить файлы в том же репозитории.

## Настройки контактов
site-config.js:
- consultationUsername: действующий контакт школы без @. Сейчас AvenzaireEDU, тот же учебный контакт, что в боте.
- botUsername: настоящий username вашего бота без @. Пока пусто, кнопка «Вернуться в бот» скрыта. После заполнения ведёт на /start direction; ответы туда не передаются автоматически.

Неверный username бота не используется. Ссылка на консультацию не записывает человека на определённое время и не отправляет сообщение сама. Формат и время нужно согласовать в Telegram. Оператор школы должен реально принимать бесплатные обращения; до публичного запуска проверьте контакт. Смена контакта в файле не меняет отдельно настроенный MENTOR_URL в боте.

## Как устроен результат
Вопросы 1–8 сопоставляют интерес к логике/поведению программ и интерфейсам/удобству. Вопросы 9–10 уточняют темп и запрос и не влияют на направление. Смешанные ответы не заставляют выбрать одну сторону. Пять и больше «не знаю» среди первых восьми или слишком мало сигналов → знакомство. При небольшой разнице → обе пробы. Открытая логика — quiz-data.mjs.

Это эвристика для разговора, не валидированный тест профориентации, не психологическая диагностика, оценка интеллекта или гарантия профессии. GitHub — бесплатный навык работы с проектами, не отдельная обещанная профессия. Нет попытки определить возраст, доход, здоровье или семейную ситуацию.

## Локальный просмотр
Из папки сайта: `python -m http.server 8000`, затем http://localhost:8000. Двойной клик index.html может блокировать JS-модули правилами браузера. После публикации используйте HTTPS.

Тесты и исходники бота находятся в отдельном архиве. Этот архив содержит только публичный сайт.
